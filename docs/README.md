# Gengar TCG Prices
Personal offline-capable PWA showing Pokémon TCG card prices from PriceCharting (eBay / 集换社 not connected yet). Static files only; no secrets. Collection data stays in your browser's localStorage (use Export for backups).

- `watchlist.json` – the cards tracked (id, name, set, number, language, PriceCharting url). Only `url` is required for new entries; the refresh fills in the rest.
- `prices.json` – latest prices, regenerated by the refresh script.
- `history/<id>.json` – monthly history from PriceCharting + one daily snapshot per refresh.

## Adding cards
Easiest: tell Grok Bot in chat (or tap "Copy request for Grok Bot" on a pending card). It adds the URL to `watchlist.json` and runs the refresh. You can also edit `watchlist.json` on GitHub yourself. The app's "Add card" saves the card as *pending* on your phone until the next refresh.
